# Task 01-2 - 플레이어 이동과 칼 공격

## 설명
플레이어가 사각형 방 안에서 WASD로 이동하고, 마우스 클릭 또는 지정 키 입력으로 단발 근접 칼 공격을 한 번씩 사용할 수 있게 한다. 공격 입력을 했을 때 공격이 나갔는지 눈으로 확인할 수 있어야 한다.

## 구현 항목
- [x] 플레이어가 사각형 방 안에서 WASD로 이동할 수 있다.
- [x] 플레이어가 마우스 클릭 또는 지정 키 입력으로 단발 근접 칼 공격을 사용할 수 있다.
- [x] 공격 입력을 했을 때 공격이 나갔는지 눈으로 확인할 수 있다.

## 범위 밖

- 음식 생성
