# Task 01-10 - 일반 동물 체력과 음식 드롭

## 설명
플레이어가 일반 동물을 칼로 3회 타격하면 일반 동물이 처치되고, 처치된 위치에 플레이어가 알아보기 쉬운 음식이 1개 이상 남는다. 칼 공격이 일반 동물에게 맞았는지 플레이 중 눈으로 확인할 수 있는 반응이 있어야 한다.

## 구현 항목
- [x] 일반 동물은 칼 공격을 3회 맞으면 처치된다.
- [x] 칼 공격이 일반 동물에게 맞았는지 알 수 있는 피격 반응이 나타난다.
- [x] 처치된 일반 동물은 사라진다.
- [x] 처치된 일반 동물은 음식 1개 이상을 남긴다.
- [x] 음식은 플레이어가 플레이 중 알아보기 쉬운 형태로 보인다.

## 범위 밖
- 보스전
- 결과 화면
- 점수 계산
- 음식 획득 효과
- 공격 애니메이션 교체
- 최종 모델 연동

## 사전 전제
- 01-3의 칼 공격 입력 흐름이 준비되어 있다.
- 01-7의 일반 동물 스폰 흐름이 준비되어 있다.
- 01-9의 칼 공격 부채꼴 대상 판정 흐름이 준비되어 있다.

## 수동 작업 (구현 후 구체화)
- Unreal Editor에서 C++ 변경 사항을 컴파일한다.
- 기존 `Content/Blueprints/BP_RegularAnimal` Blueprint를 열고, 필요하면 `CombatComponent`의 `Max Knife Hits`, `Hit Reaction Visible Time`, `Food Pickup Class`, `Food Drop Count`, `Food Drop Spacing`, `Food Drop Height` 값을 확인하기 쉬운 수준으로 조정한 뒤 저장한다.
- 기본 음식 표시를 바꾸고 싶으면 `FoodPickup` C++ 클래스를 기반으로 `Content/Blueprints/BP_FoodPickup` Blueprint를 만들고, 기존 `Content/Blueprints/BP_RegularAnimal`의 `CombatComponent`에서 `Food Pickup Class`로 연결한 뒤 저장한다.
