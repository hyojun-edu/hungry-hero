# Task 01-12 - 일반 동물 피격 스턴

## 설명
플레이어의 칼 공격에 맞아 넉백된 일반 동물이 직후 1초 동안 행동을 멈춘다. 멈춘 동안에는 플레이어에게 접근하거나 돌진 예고와 돌진을 시작하지 않으며, 1초가 지나면 기존 일반 동물 행동 흐름으로 돌아간다.

## 구현 항목
- [x] 일반 동물이 칼 공격에 맞아 넉백된 직후 1초 동안 행동을 멈춘다.
- [x] 일반 동물이 멈춘 동안 플레이어에게 접근하지 않는다.
- [x] 일반 동물이 멈춘 동안 돌진 예고나 돌진을 시작하지 않는다.
- [x] 일반 동물이 돌진 예고 또는 돌진 중 칼 공격에 맞으면 돌진을 중단하고 1초 동안 멈춘다.
- [x] 1초가 지나면 일반 동물이 기존 행동 흐름으로 돌아간다.

## 범위 밖
- 스턴 UI
- 별도 상태이상 아이콘
- 추가 데미지 계산
- 복잡한 물리 시뮬레이션

## 사전 전제
- 01-9의 칼 공격 부채꼴 대상 판정 흐름이 준비되어 있다.
- 01-10의 일반 동물 피격, 처치, 음식 드롭 흐름이 준비되어 있다.
- 01-11의 일반 동물 피격 넉백 흐름이 준비되어 있다.

## 수동 작업 (구현 후 구체화)
- Unreal Editor에서 C++ 변경 사항을 컴파일한다.
- 기존 `Content/Blueprints/BP_RegularAnimal` Blueprint를 열고, 필요하면 `Hit Stun Time` 값을 눈으로 확인하기 쉬운 수준으로 조정한 뒤 저장한다.
