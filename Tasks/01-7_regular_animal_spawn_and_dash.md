# Task 01-7 - 일반 동물 스폰과 돌진

## 설명
일반 동물이 방 가장자리 근처에서 반복해서 나타나 플레이어에게 접근하고, 플레이어가 방향을 보고 피할 수 있는 돌진 행동을 한다. 돌진 중인 일반 동물과 플레이어가 부딪치면 플레이어 체력이 10 감소한다.

## 구현 항목
- [x] 일반 동물이 플레이 중 반복해서 스폰된다.
- [x] 일반 동물이 방 가장자리 근처에서 나타난다.
- [x] 일반 동물이 플레이어를 향해 접근한다.
- [x] 일반 동물이 일정 상황에서 돌진한다.
- [x] 플레이어가 일반 동물의 돌진 방향을 보고 측면으로 피할 수 있다.
- [x] 돌진 중인 일반 동물과 부딪치면 플레이어 체력이 10 감소한다.

## 범위 밖
- 동물 처치 후 음식 생성
- 점수 계산
- 보스 또는 특수 동물
- 최종 동물 모델, 애니메이션, 사운드, 이펙트

## 사전 전제
- 01-6의 플레이어 체력 감소와 게임오버 흐름이 준비되어 있다.

## 수동 작업 (구현 후 구체화)
- Unreal Editor에서 C++ 변경 사항을 컴파일한다.
- `RegularAnimal` C++ 클래스를 기반으로 `Content/Blueprints/BP_RegularAnimal` Blueprint를 만든다.
- `RegularAnimalSpawner` C++ 클래스를 기반으로 `Content/Blueprints/BP_RegularAnimalSpawner` Blueprint를 만든다.
- `BP_RegularAnimalSpawner`의 `Regular Animal Class`를 `BP_RegularAnimal`로 설정한다.
- `Content/Maps/L_PrototypeRoom` 맵에 `BP_RegularAnimalSpawner`를 1개 배치하고 저장한다.
