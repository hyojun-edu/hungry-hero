# Task 01-1 - 사각형 방과 고정 카메라

## 설명
플레이어가 움직일 수 있는 벽으로 둘러싸인 사각형 방 하나와, 방 전체 및 플레이어 주변 상황을 보기 쉬운 고정 시점 카메라를 준비한다.

## 구현 항목
- [x] 벽으로 둘러싸인 사각형 방 하나가 준비된다.
- [x] 플레이어 시작 위치가 방 중앙 또는 중앙 근처에 배치된다.
- [x] 방 전체와 플레이어 주변 상황을 보기 쉬운 고정 시점 카메라가 준비된다.
- [x] 결과 확인이 가능하도록 기본 방향성 조명이 준비된다.
- [x] 플레이어가 방 안에서 움직일 수 있다.

## 범위 밖
- 적 생성
- 음식 생성
- 체력 시스템
- 점수 시스템
- 보스 관련 요소

## 수동 작업 (구현 후 구체화)
1. Unreal Editor에서 C++ 변경 사항을 컴파일한다.
2. 새 테스트용 맵을 만들거나 현재 테스트할 맵을 연다.
3. `PrototypeRoom` Actor를 맵에 배치하고 위치를 `0, 0, 0` 근처로 둔다.
4. `FixedRoomCamera` Actor를 맵에 배치한다. 기본 위치는 `-900, 0, 900`이며 `TargetLocation` 기본값인 `0, 0, 0`을 바라본다.
5. `PlayerStart`를 방 중앙 또는 중앙 근처에 배치한다.
6. 맵을 저장한다.

- [x] 로컬 정적 점검 또는 프로젝트 구조 기준 확인 완료
- [x] Unreal C++/Blueprint/에셋 규칙 위반 없음

### 결과 확인 (구현 후 구체화)
- [x] Unreal Editor에서 저장한 테스트 맵을 연다.
- [x] PIE를 실행했을 때 플레이어 큐브가 방 중앙 또는 중앙 근처에서 시작하는지 확인한다.
- [x] 화면이 고정 카메라 시점으로 표시되고 방 전체와 플레이어 주변 상황이 보기 쉬운지 확인한다.
- [x] 방 내부와 플레이어 큐브가 DirectionalLight로 충분히 밝게 보이는지 확인한다.
- [x] `W`, `A`, `S`, `D` 입력으로 플레이어 큐브가 방 안에서 움직이는지 확인한다.
- [x] 플레이어 큐브가 벽을 통과하지 않는지 확인한다.
