# Task 01-4 - 마우스 이동 방향 회전 유지

## 설명
플레이어 이동 방향으로 자동 회전하지 않고, 마우스 이동 방향만 플레이어의 정면 방향으로 사용한다. 이동 중이거나 정지 중일 때 마우스를 움직이면 마우스 이동 방향을 향해 점진적으로 회전하고, 마우스 입력이 없으면 현재 바라보는 방향을 유지해야 한다.

## 구현 항목
- [x] 이동 중 마우스를 움직이지 않으면 플레이어는 현재 바라보는 방향을 유지한다.
- [x] 이동 중 마우스를 움직이면 마우스 이동 방향이 플레이어 정면 방향으로 적용된다.
- [x] 정지 상태에서 마우스를 움직이면 마우스 이동 방향이 플레이어 정면 방향으로 적용된다.
- [x] `SpaceBar` 또는 마우스 왼쪽 클릭 공격 직전의 정면은 현재 실제 플레이어가 바라보는 방향을 기준으로 판단된다.
