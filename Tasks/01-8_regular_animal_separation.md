# Task 01-8 - 일반 동물 겹침 방지

## 설명
일반 동물들이 스폰되거나 이동할 때 서로 같은 위치에 겹쳐 보이지 않고, 서로 밀리거나 막히는 방식으로 분리되어 보인다. 기존 플레이어 돌진 충돌 데미지 판정과 방 벽 충돌은 유지한다.

## 구현 항목
- [x] 일반 동물들이 스폰될 때 서로 같은 위치에 겹쳐 보이지 않는다.
- [x] 일반 동물들이 이동 중 서로 겹쳐 지나가지 않고 분리되어 보인다.
- [x] 일반 동물과 플레이어의 돌진 충돌 데미지 판정이 유지된다.
- [x] 일반 동물이 방 벽 밖으로 쉽게 빠져나가지 않는다.

## 범위 밖
- 복잡한 무리 이동 AI
- 길찾기
- 동물 회피 알고리즘
- 동물 체력 감소
- 동물 처치
- 음식 생성

## 사전 전제
- 01-7의 일반 동물 스폰과 돌진 흐름이 준비되어 있다.

## 수동 작업 (구현 후 구체화)
- Unreal Editor에서 C++ 변경 사항을 컴파일한다.
- 기존 `Content/Blueprints/BP_RegularAnimal` Blueprint를 열고, 필요하면 `Separation Radius`와 `Separation Push Speed` 값을 눈으로 구분 가능한 수준으로 조정한 뒤 저장한다.
- 기존 `Content/Blueprints/BP_RegularAnimalSpawner` Blueprint를 열고, 필요하면 `Min Animal Spawn Distance`와 `Max Spawn Location Attempts` 값을 눈으로 구분 가능한 수준으로 조정한 뒤 저장한다.
