# Task 01-6 - 플레이어 체력 감소와 게임오버

## 설명
플레이어 체력이 시간이 지나면서 줄어들고, 체력이 0이 되면 게임오버 상태가 되도록 준비한다. 플레이어 체력 기준값은 100이며, 음식이 없는 상태에서는 약 30초 뒤 체력이 0이 되도록 감소해야 한다. 플레이 화면에는 현재 체력을 알 수 있는 체력바가 표시되고, 체력이 0이 되면 게임오버 화면이나 게임오버 문구가 표시되어야 한다.

## 구현 항목
- [x] 플레이어 체력 기준값은 100으로 적용된다.
- [x] 음식이 없는 상태에서 체력이 초당 약 3.33씩 감소한다.
- [x] 음식이 없는 상태로 약 30초가 지나면 체력이 0이 된다.
- [x] 플레이 화면에서 현재 체력을 알 수 있는 체력바가 표시된다.
- [x] 체력이 0이 되면 게임오버 상태가 된다.
- [x] 게임오버 상태가 되면 게임오버 화면이나 게임오버 문구가 표시된다.

## 수동 작업 (구현 후 구체화)
1. Unreal Editor에서 C++ 변경 사항을 컴파일한다.
2. `BP_PlayerCharacter`를 열고 inherited component에 `HealthComponent`가 추가되어 있는지 확인한 뒤 Blueprint를 컴파일하고 저장한다.
3. `BP_HungryHeroGameMode`를 열고 `HUD Class`를 `HungryHeroHealthHud`로 설정한다.
4. 테스트 맵의 `World Settings`에서 `GameMode Override`가 `BP_HungryHeroGameMode`인지 확인한다.
5. 테스트 맵을 저장한다.
