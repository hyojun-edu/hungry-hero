# Task 01-14 - 게임오버 시 플레이 정지

## 설명
플레이어 체력이 0이 되어 게임오버 상태가 되면 일반 동물 스폰, 일반 동물 행동, 플레이어 조작, 음식 획득 처리가 멈춘다. 기존 게임오버 문구 또는 화면 표시는 유지한다.

## 구현 항목
- [x] 게임오버 상태가 되면 일반 동물 스포너가 새 일반 동물을 더 만들지 않는다.
- [x] 게임오버 상태가 되면 이미 생성된 일반 동물은 접근을 멈춘다.
- [x] 게임오버 상태가 되면 이미 생성된 일반 동물은 돌진 예고와 돌진을 멈춘다.
- [x] 게임오버 상태가 되면 이미 생성된 일반 동물은 플레이어에게 충돌 피해를 주지 않는다.
- [x] 게임오버 상태가 되면 플레이어 이동, 회전, 칼 공격 입력이 더 이상 처리되지 않는다.
- [x] 체력이 0이 된 뒤에는 음식 획득, 체력 회복, 점수 획득이 더 이상 진행되지 않는다.
- [x] 기존 게임오버 문구 또는 화면 표시는 유지된다.
