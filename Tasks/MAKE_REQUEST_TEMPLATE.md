# 사용자 요청

- 아래 내용을 기반으로 `docs/PLANS.md`의 작업리스트 단계 하나를 작성해줘
- 그 이후에 해당 단계의 task 파일을 새로 만들어줘
- 단, 아래 두 가지 경우에는 진행하지 말고 이유를 먼저 알려줘.
    - 이전 task 다음 순서로 오기에 적합하지 않을 때
    - 현재 task의 범위가 너무 클 때

## 원하는 동작

- 일반 동물이 플레이어의 공격 범위에 들어오면 별도 공격 입력 없이 칼 공격이 자동으로 발동되고, 플레이어는 남은 공격 쿨타임을 직관적으로 알 수 있다.

## 세부 설명

- 모바일 포팅을 고려해 기본 플레이 입력을 이동과 방향 전환 중심으로 줄인다.
- 일반 동물이 플레이어 공격 범위 안에 들어오면 SpaceBar 같은 명시적 공격 입력 없이 자동으로 공격이 발동된다.
- 자동 공격은 기존 칼 공격의 방향과 범위 판정을 기준으로 한다.
- 공격이 한 번 발동된 뒤에는 1초 동안 다시 공격하지 못한다.
- 공격 쿨타임이 얼마나 남았는지 플레이어가 플레이 중 바로 알아볼 수 있게 표시한다.
- 쿨타임 표시는 플레이어가 동물에게 접근할지, 거리를 벌릴지, 방향을 바꿀지 판단하는 데 도움이 될 만큼 읽기 쉬워야 한다.
- 이번 task에서는 모바일 터치 UI, 가상 조이스틱, 새로운 공격 종류, 공격 콤보는 만들지 않는다.
