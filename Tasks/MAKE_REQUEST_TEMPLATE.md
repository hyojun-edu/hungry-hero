# 사용자 요청

- 아래 내용을 기반으로 `docs/PLANS.md`의 작업리스트 단계 하나를 작성해줘
- 그 이후에 해당 단계의 task 파일을 새로 만들어줘
- 단, 아래 두 가지 경우에는 진행하지 말고 이유를 먼저 알려줘.
    - 이전 task 다음 순서로 오기에 적합하지 않을 때
    - 현재 task의 범위가 너무 클 때

## 원하는 동작

- 플레이어가 이동 입력과 마우스 입력 우선순위에 따라 자연스럽게 바라보는 방향을 정한다.

## 세부 설명

- 이동 중 마우스를 움직이지 않으면 플레이어는 이동 방향을 바라본다.
- 이동 중 마우스를 움직이면 마우스 방향 회전이 우선된다.
- 정지 상태에서는 기존처럼 마우스 회전만 유지한다.
- SpaceBar 공격 직전의 정면은 현재 실제 플레이어가 바라보는 방향을 기준으로 판단한다.
- 이번 task에서는 공격 범위 판정, 적 피격, 체력 감소, 음식 생성은 만들지 않는다.
