# 사용자 요청

- 아래 내용을 기반으로 `docs/PLANS.md`의 작업리스트 단계 하나를 작성해줘
- 그 이후에 해당 단계의 task 파일을 새로 만들어줘
- 단, 아래 두 가지 경우에는 진행하지 말고 이유를 먼저 알려줘.
    - 이전 task 다음 순서로 오기에 적합하지 않을 때
    - 현재 task의 범위가 너무 클 때

## 원하는 동작

- 현재 프로토타입을 Android 모바일 빌드 대상으로 전환하고, 모바일 화면과 입력 조건에서 핵심 플레이가 실행 가능한지 확인한다.

## 세부 설명

- Unreal 프로젝트의 Android 플랫폼 설정을 준비한다.
- Android 빌드 또는 패키징이 가능한 상태인지 확인한다.
- 실제 Android 기기 또는 에뮬레이터에서 실행 가능한지 확인한다.
- 모바일 화면 비율에서 체력, 점수, 공격 쿨타임 표시가 읽기 쉬운지 확인한다.
- 이동과 방향 전환 중심의 현재 조작 구조가 모바일 포팅 기준으로 유지 가능한지 확인한다.
- 자동 공격이 모바일 환경에서도 별도 공격 버튼 없이 발동되는지 확인한다.
- 이번 task에서는 Google Play 출시, 광고, 결제, 최종 최적화, 모바일 전용 터치 UI 대개편, 보스전 추가, 그래픽 품질 세부 튜닝은 만들지 않는다.
