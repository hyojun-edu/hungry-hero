# 사용자 요청

- 아래 내용을 기반으로 `docs/PLANS.md`의 작업리스트 단계 하나를 작성해줘
- 그 이후에 해당 단계의 task 파일을 새로 만들어줘
- 단, 아래 두 가지 경우에는 진행하지 말고 이유를 먼저 알려줘.
    - 이전 task 다음 순서로 오기에 적합하지 않을 때
    - 현재 task의 범위가 너무 클 때

## 원하는 동작

- 플레이어가 음식에 닿으면 음식을 획득하고 체력이 회복되며 점수가 오른다.

## 세부 설명

- 음식 1개는 플레이어 체력을 20 회복한다.
- 체력은 최대 체력 100을 넘지 않도록 한다.
- 음식 획득 시 현재 점수가 증가한다.
- 플레이 화면에는 현재 점수를 표시한다.
- 음식 획득 효과나 간단한 효과음은 시간이 허용되면 붙인다.
