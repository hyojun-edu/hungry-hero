## 원하는 동작

- 일반 동물과 플레이어가 서로 겹쳐 지나가는 오버랩 느낌이 아니라, 서로 몸으로 막히고 밀리는 충돌처럼 보인다.

## 세부 설명

- 일반 동물은 플레이어에게 접근하거나 돌진할 때 플레이어 몸을 그대로 통과하지 않는다.
- 플레이어도 일반 동물과 닿았을 때 동물 몸을 그대로 뚫고 지나가지 않는다.
- 돌진 중인 일반 동물과 플레이어가 부딪치면 기존 체력 감소 판정은 유지한다.
- 동물 간 겹침 방지와 방 벽 충돌은 기존처럼 유지한다.
- 음식 획득처럼 의도적으로 닿아서 얻는 대상은 기존 오버랩 흐름을 유지한다.
- 이번 task에서는 보스전, 보스 충돌, 복잡한 물리 시뮬레이션, 래그돌 반응은 만들지 않는다.
