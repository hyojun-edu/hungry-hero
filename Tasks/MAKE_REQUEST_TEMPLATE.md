# 사용자 요청

- 아래 내용을 기반으로 `docs/PLANS.md`의 작업리스트 단계 하나를 작성해줘
- 그 이후에 해당 단계의 task 파일을 새로 만들어줘
- 단, 아래 두 가지 경우에는 진행하지 말고 이유를 먼저 알려줘.
    - 이전 task 다음 순서로 오기에 적합하지 않을 때
    - 현재 task의 범위가 너무 클 때

## 원하는 동작

- 플레이어가 마우스로 바라보는 방향을 회전하고, 칼 공격은 SpaceBar로만 사용한다.

## 세부 설명

- 플레이어는 이동 중이거나 정지 중에도 마우스 위치 또는 마우스 방향 입력을 기준으로 회전할 수 있어야 한다.
- 마우스 왼쪽 클릭은 공격 입력에서 제외한다.
- SpaceBar를 눌렀을 때만 단발 칼 공격이 나간다.
- 공격 표시는 플레이어가 현재 바라보는 정면 방향에 맞춰 보인다.
- 이번 task에서는 공격 범위 판정, 적 피격, 체력 감소, 음식 생성은 만들지 않는다.
