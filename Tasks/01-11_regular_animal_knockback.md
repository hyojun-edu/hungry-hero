# Task 01-11 - 일반 동물 피격 넉백

## 설명
플레이어의 칼 공격에 맞은 일반 동물이 타격감을 느낄 수 있게 플레이어 반대 방향으로 짧게 밀려난다. 넉백은 기존 피격 반응과 함께 보이며, 일반 동물의 3회 피격 처치와 음식 생성 흐름은 유지된다.

## 구현 항목
- [x] 일반 동물이 칼 공격에 맞으면 플레이어 반대 방향으로 짧게 밀려난다.
- [x] 넉백은 기존 동물 피격 반응과 함께 보인다.
- [x] 일반 동물이 돌진 중이거나 돌진 예고 중일 때 칼 공격에 맞으면 돌진을 중단하고 넉백된다.
- [x] 넉백 중에도 일반 동물이 방 벽 밖으로 쉽게 빠져나가지 않는다.
- [x] 넉백 때문에 일반 동물의 3회 피격 처치 흐름이 깨지지 않는다.
- [x] 넉백 때문에 처치 후 음식 생성 흐름이 깨지지 않는다.

## 범위 밖
- 복잡한 물리 시뮬레이션
- 스턴 상태
- 추가 데미지 계산
- 음식 획득
- 체력 회복
- 점수 계산

- 01-10의 일반 동물 피격, 처치, 음식 드롭 흐름이 준비되어 있다.

## 수동 작업 (구현 후 구체화)

- 기존 `Content/Blueprints/BP_RegularAnimal` Blueprint를 열고, 필요하면 `CombatComponent`의 `Knockback Distance` 값을 눈으로 확인하기 쉬운 수준으로 조정한 뒤 저장한다.
