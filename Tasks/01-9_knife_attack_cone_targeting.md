# Task 01-9 - 칼 공격 부채꼴 대상 판정

## 설명
플레이어가 칼 공격을 하면 플레이어 정면 기준 좌우 30도, 전체 60도 부채꼴 범위와 앞쪽 근접 거리 안에 있는 대상만 공격 후보로 판정된다. 공격 후보 범위는 큐브가 아닌 부채꼴 형태로 플레이 중 눈으로 확인할 수 있어야 한다.

## 구현 항목
- [x] 칼 공격 시 플레이어 정면 기준 좌우 30도, 전체 60도 안의 대상만 공격 후보로 판정된다.
- [x] 칼 공격 후보 판정은 플레이어 앞쪽 근접 거리 안의 대상만 포함한다.
- [x] 공격 범위 안에 대상이 있는지 큐브가 아닌 부채꼴 형태의 표시로 플레이 중 눈으로 확인할 수 있다.
- [x] 공격 범위 밖의 대상은 공격 후보로 판정되지 않는다.

## 범위 밖
- 동물 체력 감소
- 동물 처치
- 음식 생성
- 점수 계산
- 공격 애니메이션 교체
- 최종 모델 연동

## 사전 전제
- 01-3의 칼 공격 입력 흐름이 준비되어 있다.
- 01-7의 일반 동물 스폰 흐름이 준비되어 있다.

## 수동 작업 (구현 후 구체화)
- Unreal Editor에서 C++ 변경 사항을 컴파일한다.
- 기존 `Content/Blueprints/BP_PlayerCharacter` Blueprint를 열고, 필요하면 `KnifeAttackComponent`의 `Attack Range`, `Attack Half Angle Degrees`, `Attack Debug Visible Time`, `Attack Debug Segment Count`, `Attack Debug Height` 값을 눈으로 확인하기 쉬운 수준으로 조정한 뒤 저장한다.
