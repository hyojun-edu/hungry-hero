# Task 01-13 - 음식 획득과 체력 회복 점수

## 설명
플레이어가 음식에 닿으면 음식이 획득되고, 플레이어 체력이 회복되며 현재 점수가 오른다. 체력은 최대 체력을 넘지 않아야 하고, 플레이 화면에서 현재 점수를 확인할 수 있어야 한다.

## 구현 항목
- [x] 플레이어가 음식에 닿으면 음식을 획득한다.
- [x] 음식 1개를 획득하면 플레이어 체력이 20 회복된다.
- [x] 체력 회복 후 플레이어 체력은 최대 체력 100을 넘지 않는다.
- [x] 음식 획득 시 현재 점수가 100 증가한다.
- [x] 플레이 화면에서 현재 점수를 확인할 수 있다.
- [x] 음식 표시 위의 `FOOD` 라벨은 더 이상 보이지 않는다.

## 수동 작업 (구현 후 구체화)
- Unreal Editor에서 C++ 변경 사항을 컴파일한다.
- 기존 `Content/Blueprints/BP_PlayerCharacter` Blueprint를 열고 inherited component에 `ScoreComponent`가 추가되어 있는지 확인한 뒤 `Food Score Value`가 `100`인지 확인하고 Blueprint를 컴파일한 뒤 저장한다.
- `BP_HungryHeroGameMode`의 `HUD Class`가 기존처럼 `HungryHeroHealthHud`로 설정되어 있는지 확인한다.
- 기본 음식 회복량을 확인하고 싶으면 `FoodPickup` 또는 이를 기반으로 만든 음식 Blueprint에서 `Heal Amount`가 `20`인지 확인한다.
