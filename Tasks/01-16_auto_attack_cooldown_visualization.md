# Task 01-16 - 자동 공격 전환과 쿨타임 시각화

## 설명
일반 동물이 플레이어의 공격 범위에 들어오면 별도 공격 입력 없이 칼 공격이 자동으로 발동되도록 전환한다. 공격에는 1초 쿨타임이 있으며, 플레이어가 남은 쿨타임을 직관적으로 보고 이동과 방향 전환 판단에 반영할 수 있어야 한다.

## 구현 항목
- [x] 일반 동물이 플레이어 공격 범위 안에 들어오면 명시적 공격 입력 없이 자동으로 칼 공격이 발동된다.
- [x] 자동 공격은 기존 칼 공격의 방향과 범위 판정을 기준으로 한다.
- [x] 공격이 한 번 발동된 뒤에는 1초 동안 다시 공격하지 못한다.
- [x] 플레이어가 공격 쿨타임이 얼마나 남았는지 플레이 중 바로 알아볼 수 있다.
- [x] 쿨타임 표시는 플레이어가 동물에게 접근할지, 거리를 벌릴지, 방향을 바꿀지 판단하는 데 도움이 될 만큼 읽기 쉽다.

## 범위 밖
- 모바일 터치 UI
- 가상 조이스틱
- 새로운 공격 종류
- 공격 콤보
- 보스전
- 결과 화면
- 최종 UI 디자인

- 01-9의 칼 공격 범위 판정이 구현되어 있다.
- 01-10의 일반 동물 체력과 음식 드롭 흐름이 구현되어 있다.

- 01-15의 동물과 플레이어 충돌 처리 정리가 구현되어 있다.
