# 게임 기획서: 헝그리 히어로

## 1. 게임 개요
- 한 줄 소개: 줄어드는 체력을 관리하며 돌진하는 동물을 피하고 칼로 처치해 음식으로 바꿔 살아남는 캐주얼 3D 아레나 액션 게임.
- 장르: 고정 카메라 아레나 액션.
- 플랫폼: PC.
- 엔진: Unreal Engine 5.8.
- 대상 플레이 시간: 1회 약 1분 30초 내외.

## 2. 제작 범위
- 팀 규모: 1인.
- 제작 기간: 1주일.
- 사용자의 Unreal 숙련도: 초보.
- 최종 제출물: 플레이 가능한 게임 프로젝트.
- 구현 가능한 범위 요약: 사각형 방 하나에서 플레이어가 이동, 공격, 회피, 음식 획득을 반복하는 작은 프로토타입을 만든다. 보스전은 시간이 남으면 넣는 확장 기능으로 둔다.

## 3. 핵심 플레이
- 플레이어가 가장 자주 하는 행동: 동물의 돌진 모션을 보고 측면으로 이동한 뒤, 칼을 휘둘러 타격한다.
- 재미의 중심: 돌진을 인식하고 피한 다음 빈틈을 공격하는 조작감.
- 기본 플레이 흐름: 체력이 자동으로 감소한다 -> 일반 동물이 스폰되어 플레이어를 향해 접근하고 돌진한다 -> 플레이어가 측면으로 피하고 칼로 공격한다 -> 동물을 처치하면 음식으로 변한다 -> 음식을 획득해 체력을 회복한다 -> 1분 뒤 보스가 등장한다 -> 보스를 처치하면 음식이 많이 흩어진다 -> 10초 동안 음식을 모은 뒤 결과 화면에서 점수를 확인한다.

## 4. 조작
- 이동: 키보드 WASD.
- 시점/카메라: 사각형 방 전체를 보기 쉬운 고정 카메라.
- 상호작용: 음식에 닿으면 자동 획득.
- 기타 조작: 마우스 클릭 또는 지정 키로 칼 공격. 초보 제작 범위에 맞춰 복잡한 콤보 없이 단발 근접 공격으로 구현한다.

## 5. 규칙과 목표
- 성공 조건: 보스를 처치한 뒤 10초 동안 음식을 수집하고 결과 화면에 도달한다.
- 실패 조건: 플레이어 체력이 0이 되면 게임오버.
- 점수/체력/시간/자원: 플레이어 체력 기준값은 100. 체력은 초당 약 3.33 감소해 음식을 먹지 않으면 30초 후 0이 된다. 음식 1개는 체력 20을 회복해 약 6초를 더 버틸 수 있다. 돌진 중인 동물과 부딪치면 체력 10이 감소한다. 음식의 종류와 개수에 따라 최종 점수를 합산한다.
- 주요 규칙: 일반 동물은 칼 공격 3회에 처치된다. 보스는 칼 공격 30회에 처치된다. 보스는 게임 시작 후 1분 뒤 등장한다. 보스 처치 후 10초가 지나면 결과 화면으로 전환된다.

## 6. 콘텐츠 목록
- 플레이어: 키보드로 움직이고 칼로 근접 공격하는 캐릭터.
- 적/NPC: 플레이어를 향해 이동하다가 돌진하는 일반 동물, 크고 체력이 많은 보스.
- 아이템: 체력을 회복하고 최종 점수에 반영되는 음식.
- 장애물: 사각형 방의 벽.
- 상호작용 오브젝트: 음식 픽업, 공격 판정, 일반 동물의 음식 변환 이펙트, 보스 음식 분출 이펙트.

## 7. 레벨/맵
- 공간 구성: 벽으로 둘러싸인 사각형 방 하나.
- 시작 지점: 방 중앙 또는 중앙 근처.
- 주요 구역: 동물이 방 가장자리 근처에서 랜덤하게 스폰되고, 플레이어는 중앙과 측면 공간을 오가며 돌진을 피한다.
- 종료 지점: 별도 지점 없이 보스 처치 후 10초가 지나면 결과 화면으로 전환된다.

## 8. UI
- 시작 화면: 1주일 범위에서는 생략 가능. 실행 후 바로 플레이 화면으로 들어간다.
- 플레이 화면 HUD: 플레이어 체력바, 현재 점수.
- 결과/종료 화면: 체력 0일 때 게임오버 화면, 보스 처치 후 10초 뒤 음식 종류와 개수에 따른 결과 화면.
- 필요한 안내 문구: 보스 등장 시 짧은 알림, 체력 0 시 게임오버, 결과 화면의 최종 점수 표시.

## 9. 아트/사운드
- 아트 방향: 캐주얼하고 읽기 쉬운 3D 스타일. 판정과 움직임이 잘 보이는 것이 우선이다.
- 사용할 에셋: 무료 에셋과 언리얼 기본 리소스.
- 필요한 사운드: 칼 공격, 동물 피격, 음식 생성, 음식 획득, 보스 등장, 게임오버, 결과 화면 효과음.
- 대체 가능한 요소: 동물, 음식, 이펙트는 무료 에셋이 없으면 언리얼 기본 메시와 간단한 파티클 또는 색상 변화로 대체한다.

## 10. 구현 우선순위
### 반드시 구현
- 플레이어 이동.
- 플레이어 칼 공격.
- 플레이어 체력 자동 감소.
- 체력바 표시.
- 일반 동물 스폰.
- 일반 동물의 플레이어 접근과 돌진.
- 일반 동물 피격 및 처치.
- 일반 동물 처치 후 음식 생성.
- 음식 획득과 체력 회복.
- 체력 0 게임오버.

### 가능하면 구현
- 공격 이펙트.
- 일반 동물의 음식 변환 이펙트.
- 음식 획득 효과.
- 현재 점수 표시.
- 간단한 효과음.

### 시간이 남으면 구현
- 1분 후 보스 등장.
- 보스 체력바.
- 보스 피격과 처치.
- 보스 음식 분출 이펙트.
- 보스 처치 후 10초 카운트.
- 최종 결과 화면.

## 11. 제외할 것
- 멀티플레이.
- 여러 맵.
- 복잡한 동물 AI.
- 장비 성장.
- 긴 스토리.
- 인벤토리.
- 캐릭터 성장 시스템.
- 복잡한 공격 콤보.

## 12. 개발 일정
- 1단계: 1일차에 기본 프로젝트를 정리하고 사각형 방, 벽, 고정 카메라를 만든다.
- 2단계: 2일차에 플레이어 이동과 단발 칼 공격을 만든다.
- 3단계: 3일차에 체력 자동 감소, 체력바, 체력 0 게임오버를 만든다.
- 4단계: 4일차에 일반 동물 스폰, 접근, 돌진, 피격 판정을 만든다.
- 5단계: 5일차에 동물 처치 후 음식 생성, 음식 획득, 체력 회복을 만든다.
- 6단계: 6일차에 공격 이펙트, 음식 변환 이펙트, 점수 표시, 결과 화면을 가능한 범위에서 붙인다.
- 마감 전 점검: 7일차에 버그를 수정하고, 플레이 시작부터 게임오버 또는 결과 화면까지 끊기지 않는지 확인한 뒤 제출용 프로젝트를 정리한다.
