# Task 01 - 기본 플레이 공간

## 원하는 동작

- 플레이어가 움직일 수 있는 사각형 방과 고정 카메라가 준비된다.

## 세부 설명

- 벽으로 둘러싸인 사각형 방 하나를 만든다.
- 플레이어 시작 위치는 방 중앙 또는 중앙 근처로 둔다.
- 카메라는 방 전체와 플레이어 주변 상황을 보기 쉬운 고정 시점으로 둔다.
- 이번 task에서는 적, 음식, 체력, 점수, 보스는 만들지 않는다.

# Task 02 - 플레이어 이동과 단발 공격

## 원하는 동작

- 플레이어가 WASD로 이동하고 마우스 클릭 또는 지정 키로 칼 공격을 한 번씩 사용할 수 있다.

## 세부 설명

- 플레이어는 사각형 방 안에서 이동할 수 있어야 한다.
- 공격은 복잡한 콤보 없이 단발 근접 공격으로 만든다.
- 공격 입력을 했을 때 공격이 나갔는지 눈으로 확인할 수 있어야 한다.
- 이번 task에서는 적 피격, 체력 감소, 음식 생성은 만들지 않는다.

# Task 03 - 마우스 방향 회전과 공격 입력 정리

## 원하는 동작

- 플레이어가 마우스로 바라보는 방향을 회전하고, 칼 공격은 SpaceBar 또는 마우스 왼쪽 클릭으로 사용한다.

## 세부 설명

- 플레이어는 이동 중이거나 정지 중에도 마우스 위치 또는 마우스 방향 입력을 기준으로 회전할 수 있어야 한다.
- 마우스 왼쪽 클릭으로 단발 칼 공격이 나간다.
- SpaceBar로 단발 칼 공격이 나간다.
- 공격 표시는 플레이어가 현재 바라보는 정면 방향에 맞춰 보인다.
- 이번 task에서는 공격 범위 판정, 적 피격, 체력 감소, 음식 생성은 만들지 않는다.

# Task 04 - 마우스 이동 방향 회전 유지

## 원하는 동작

- 플레이어가 이동 방향으로 자동 회전하지 않고, 마우스 이동 방향을 기준으로 바라보는 방향을 정한다.

## 세부 설명

- 이동 중 마우스를 움직이지 않으면 플레이어는 현재 바라보는 방향을 유지한다.
- 이동 중 마우스를 움직이면 마우스 이동 방향이 플레이어 정면 방향으로 적용된다.
- 정지 상태에서 마우스를 움직이면 마우스 이동 방향이 플레이어 정면 방향으로 적용된다.
- SpaceBar 또는 마우스 왼쪽 클릭 공격 직전의 정면은 현재 실제 플레이어가 바라보는 방향을 기준으로 판단한다.
- 이번 task에서는 공격 범위 판정, 적 피격, 체력 감소, 음식 생성은 만들지 않는다.

# Task 05 - 플레이어 Blueprint 관리 전환

## 원하는 동작

- 플레이어를 C++ 클래스만 직접 쓰는 방식에서 Blueprint로 관리할 수 있는 방식으로 정리한다.

## 세부 설명

- 기존 플레이어 C++ 동작은 유지한다.
- 플레이어 Blueprint를 만들어 테스트 맵의 기본 플레이어로 사용할 수 있어야 한다.
- 이후 모델, 머티리얼, 애니메이션, 컴포넌트 연결을 Blueprint에서 조정할 수 있게 준비한다.
- C++ 코드와 Blueprint 책임이 섞이지 않도록, 핵심 입력과 기본 동작은 C++에 두고 외형과 에디터 조정은 Blueprint에서 관리한다.
- 이번 task에서는 최종 캐릭터 모델, 애니메이션 블루프린트, 체력, 적, 음식, 점수는 만들지 않는다.

# Task 06 - 플레이어 체력과 게임오버

## 원하는 동작

- 플레이어 체력이 시간이 지나면서 줄어들고, 체력이 0이 되면 게임오버 상태가 된다.

## 세부 설명

- 플레이어 체력 기준값은 100으로 둔다.
- 음식이 없으면 약 30초 뒤 체력이 0이 되도록 초당 약 3.33씩 감소한다.
- 플레이 화면에는 현재 체력을 알 수 있는 체력바를 표시한다.
- 체력이 0이 되면 게임오버 화면이나 게임오버 문구가 표시된다.
- 이번 task에서는 적, 음식, 점수, 보스는 만들지 않는다.

# Task 07 - 일반 동물 스폰과 돌진

## 원하는 동작

- 일반 동물이 방 가장자리 근처에서 나타나 플레이어에게 접근하고 돌진한다.

## 세부 설명

- 일반 동물은 플레이 중 반복해서 스폰된다.
- 일반 동물은 플레이어를 향해 이동하다가 일정 상황에서 돌진한다.
- 플레이어는 동물의 돌진 방향을 보고 측면으로 피할 수 있어야 한다.
- 돌진 중인 동물과 부딪치면 플레이어 체력이 10 감소한다.
- 이번 task에서는 동물 처치 후 음식 생성과 점수 계산은 만들지 않는다.

# Task 08 - 동물 간 겹침 방지

## 원하는 동작

- 일반 동물들이 이동하거나 스폰될 때 서로 같은 위치에 겹쳐 보이지 않는다.

## 세부 설명

- 일반 동물끼리는 서로 겹쳐 지나가지 않고 밀리거나 막히는 방식으로 분리되어 보인다.
- 플레이어와 일반 동물의 돌진 충돌 데미지 판정은 유지한다.
- 방 벽과의 충돌은 기존처럼 유지해 동물이 방 밖으로 쉽게 빠져나가지 않게 한다.
- 이번 task에서는 복잡한 무리 이동 AI, 길찾기, 동물 회피 알고리즘은 만들지 않는다.
- 이번 task에서는 동물 체력 감소, 처치, 음식 생성은 만들지 않는다.

# Task 09 - 칼 공격 범위 판정

## 원하는 동작

- 플레이어가 칼 공격을 하면 플레이어 정면 60도 각도와 일정 거리 안의 대상만 공격 후보로 판정된다.

## 세부 설명

- 공격 범위는 플레이어 정면 기준 좌우 30도, 전체 60도 부채꼴로 둔다.
- 공격 거리는 플레이어 앞 근접 범위로 제한한다.
- 공격 범위 안에 대상이 있는지 눈으로 확인할 수 있어야 한다.
- 이번 task에서는 동물 체력 감소, 처치, 음식 생성은 만들지 않는다.

# Task 10 - 동물 피격, 처치, 음식 생성

## 원하는 동작

- 플레이어가 일반 동물을 칼로 3회 타격하면 동물이 음식으로 바뀐다.

## 세부 설명

- 일반 동물은 칼 공격 3회에 처치된다.
- 공격이 동물에게 맞았는지 알 수 있는 반응이 있어야 한다.
- 처치된 동물은 사라지고 음식 1개 이상을 남긴다.
- 음식은 플레이어가 알아보기 쉬운 형태여야 한다.
- 이번 task에서는 보스전과 결과 화면은 만들지 않는다.

# Task 11 - 동물 피격 넉백

## 원하는 동작

- 칼 공격에 맞은 일반 동물이 플레이어가 타격감을 느낄 수 있게 짧게 밀려난다.

## 세부 설명

- 일반 동물이 칼 공격에 맞으면 플레이어 반대 방향으로 짧게 밀려난다.
- 넉백은 동물 피격 반응과 함께 보여야 한다.
- 넉백 중에도 방 벽 밖으로 쉽게 빠져나가지 않아야 한다.
- 넉백 때문에 일반 동물의 3회 피격 처치와 음식 생성 흐름이 깨지지 않아야 한다.
- 이번 task에서는 복잡한 물리 시뮬레이션, 스턴 상태, 추가 데미지 계산은 만들지 않는다.

# Task 12 - 음식 획득, 체력 회복, 점수

## 원하는 동작

- 플레이어가 음식에 닿으면 음식을 획득하고 체력이 회복되며 점수가 오른다.

## 세부 설명

- 음식 1개는 플레이어 체력을 20 회복한다.
- 체력은 최대 체력 100을 넘지 않도록 한다.
- 음식 획득 시 현재 점수가 증가한다.
- 플레이 화면에는 현재 점수를 표시한다.
- 음식 획득 효과나 간단한 효과음은 시간이 허용되면 붙인다.

# Task 13 - 게임오버 상태 정지 처리

## 원하는 동작

- 플레이어 체력이 0이 되어 게임오버가 되면 일반 동물 스폰, 일반 동물 행동, 플레이어 조작이 중지된다.

## 세부 설명

- 게임오버 상태가 되면 일반 동물 스포너는 새 동물을 더 만들지 않는다.
- 게임오버 상태가 되면 이미 생성된 일반 동물은 접근, 돌진 예고, 돌진, 충돌 피해 처리를 멈춘다.
- 게임오버 상태가 되면 플레이어 이동, 회전, 칼 공격 입력이 더 이상 처리되지 않는다.
- 음식 획득과 체력 회복이 이미 구현된 상태에서, 체력이 0이 된 뒤에는 더 이상 회복이나 점수 획득이 진행되지 않도록 한다.
- 기존 게임오버 문구 또는 화면 표시는 유지한다.
- 이번 task에서는 보스전과 결과 화면은 만들지 않는다.

# Task 14 - 보스 등장과 보스전

## 원하는 동작

- 게임 시작 후 1분이 지나면 보스가 등장하고, 플레이어가 보스를 공격해 처치할 수 있다.

## 세부 설명

- 보스는 일반 동물보다 크고 체력이 많아야 한다.
- 보스는 칼 공격 30회에 처치된다.
- 보스가 등장하면 플레이어가 알 수 있는 짧은 알림을 표시한다.
- 보스가 등장한 뒤에는 보스 체력바를 표시한다.
- 이 task는 시간이 남으면 구현하는 확장 범위로 둔다.

# Task 15 - 보스 처치 후 음식 분출과 결과 화면

## 원하는 동작

- 보스를 처치하면 음식이 많이 흩어지고, 10초 뒤 최종 점수 결과 화면이 나온다.

## 세부 설명

- 보스 처치 시 주변에 여러 개의 음식이 생성된다.
- 보스 처치 후 플레이어는 10초 동안 음식을 더 모을 수 있다.
- 10초가 지나면 최종 점수 화면으로 전환된다.
- 결과 화면에는 획득한 음식 종류와 개수 또는 최종 점수를 보여준다.
- 이 task는 보스전이 구현된 뒤에만 진행한다.

# Task 16 - 이펙트, 사운드, 제출 전 점검

## 원하는 동작
